# Process settings and toolpath simulation

Use **Process settings · Orca options** for Quality, Strength, Speed and Support / five-axis controls. The sidebar keeps layer height, default width, infill density, speed and support mode available. Settings are saved in projects, included in the validation fingerprint, and invalidate the previous result. Slice again after changing process settings.

| Group | Implemented generation controls |
|---|---|
| Quality | Nozzle diameter, layer height, initial layer height, default / initial / outer wall / inner wall / sparse infill / solid infill widths, seam position |
| Strength | Wall loops, outer/inner or inner/outer wall order, top and bottom shell layers, sparse infill density, rectilinear / grid / stress-aligned pattern, infill direction |
| Speed | Default speed, outer and inner walls, sparse and solid infill, support, initial layer, travel, travel Z hop |
| Support / five-axis | Normal, reduced, none; base pattern spacing, reduced spacing multiplier, maximum bridge span, orientation search cone and deposition tilt limit |

Zero role widths and role speeds inherit the default. Zero initial height inherits the layer height. Initial width and speed override the corresponding role settings on layer zero. The nozzle diameter sizes the dummy nozzle and the Orca default-width helper; imported STEP geometry is preserved. Shell counts select solid fill at the beginning and end of the scalar-field layer sequence. Local exposed surfaces in complex topology still require broader shell qualification.

These controls follow Orca's terminology and relevant option keys: [upstream print-setting groups](https://github.com/OrcaSlicer/OrcaSlicer/blob/f0e9cdc470f3eba904a9a6cc2109e3793522b103/src/slic3r/GUI/GUI_Factories.cpp), [infill documentation](https://github.com/OrcaSlicer/OrcaSlicer/wiki/strength_settings_infill). Generation uses FiveAxisLab's curved-layer engine. It does not embed every Orca option or its full planar slicing engine.

## Orca process JSON

Choose **Import Orca process JSON**, or use `--orca-process FILE`. Import numeric JSON values and Orca numeric strings, including percentage density and single-value nozzle arrays. Use a flattened preset: inherited presets are not resolved automatically. Unsupported keys are listed in the UI log or CLI diagnostics. Unsupported infill patterns, seam modes, wall sequences and numeric formats fail the import before changing the settings.

Supported keys: `layer_height`, `initial_layer_print_height`, `line_width`, `initial_layer_line_width`, `outer_wall_line_width`, `inner_wall_line_width`, `sparse_infill_line_width`, `internal_solid_infill_line_width`, `nozzle_diameter`, `wall_loops`, `top_shell_layers`, `bottom_shell_layers`, `wall_sequence`, `seam_position`, `sparse_infill_density`, `sparse_infill_pattern`, `infill_direction`, `outer_wall_speed`, `inner_wall_speed`, `sparse_infill_speed`, `internal_solid_infill_speed`, `support_speed`, `initial_layer_speed`, `travel_speed`, `z_hop`, `enable_support`, `support_base_pattern_spacing`.

Rectilinear alternates direction between layers; grid prints two perpendicular families with their spacing adjusted for the requested density. Stress-aligned infill follows tensile directions where a qualified tensor field is available. Aligned, back, nearest and deterministic random seams also work without FEM. Lowest-stress seams fall back to an aligned location when tensors are absent. Gyroid, tree supports, scarf seams, adaptive width, ironing and other unimplemented Orca features are not generated by this release.

## Support reduction

Normal mode clusters candidate support points into columns. Base pattern spacing is the gap added to the nominal support width to determine column pitch. Reduced mode multiplies that pitch, yielding fewer columns and less support extrusion. No supports creates zero support extrusion. These modes do not erase unsupported-deposition events or change the export gate. Maximum bridge span continues to bound the existing geometric deposition heuristic; it is not a material-specific bridge qualification.

## Dummy toolhead and preview

The dummy contains a nozzle, heat break, heater block and fan shroud. All four physical meshes participate in collision detection, including the limited nozzle contact rule. Machine transforms and motion limits remain active. The imported assembly and its source STEP stay in the project when the dummy is selected, and return when the option is cleared. The HUD, JSON report and exported G-code identify dummy use. Collision results cover these synthetic bodies only.

Toolpath lines are sampled from the same carriage/rotary interpolation used by motion validation, then cached for rendering in the workpiece frame. Travel is blue, outer walls orange, inner walls yellow, infill green, solid fill cyan and support purple. Deposition violations and detected collisions are marked red. Future motion is dimmed; completed motion is bright; the current partial segment is white. Full job, up to nozzle and current layer filters work in both planned and exported replay. Backward scrubbing restores the path prefix as well as deposited material. Playback visibility and speed do not modify validation.
