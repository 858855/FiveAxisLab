# Validation ledger

Version 0.3.1 adds calibrated axis frames and manual/animated tilt and roll. All 43 core cases, six native desktop workflows (including both machine layouts) and eight Python flow cases passed: 57 functional checks, excluding Qt setup/cleanup rows. New evidence covers mounted TCP compensation and pivot frames, non-printing sweeps and project round trips, actual angle playback, manual pose changes, both animated axes, Cartesian reach rejection, restoration on timeline scrubbing, unchanged planned fingerprints, retained screenshot poses and export gating. Native captures show the real OpenGL window for both layouts. The portable app opened both demonstrations without the SDK on PATH; its CLI also passed the existing reference's geometry and Duet semantic replay. Runtime hashes and archive CRC checks passed. Reports are `examples/reports/0.3.1-*`; axis captures are `axes-*.png`. Manual/animated poses and the supplied axis demonstrations remain unvalidated and non-printing. Existing controller and collision checks passed; no new native firmware or physical printing evidence is claimed.

Core checks cover geometric effects of offsets, exact final height, concentric surfaces, shell thickness, alternating walls, scheduling, adhesion and small-wall speeds; native/Orca preset parsing and material metadata; and STEP linear/angular settings, cache separation and Compound splitting. Current reports are `examples/reports/0.3.0-*`; older evidence below remains archived. No new physical or native firmware qualification is claimed. The roadmap is not fully qualified by this initial release. It implements the desktop foundation, STEP setup, collision checking, growing-material simulation, FEM core, curved slicing and controller adapters. Production claims require reference Fusion studies, larger complex-part coverage / repair fixtures, native Duet firmware checks and calibrated hardware trials.

Release checks passed: 33 core cases, one native desktop workflow case, eight Python flow cases, and five native Klipper batch cases. Init / cleanup rows in Qt's logs are not included in those counts. The reference bed and head jobs pass semantic replay. The torus fixture is blocked by its report. The larger curved-stress fixture generates approximately 26,000 coordinated movements and reaches the 180-second validation budget; its saved preview is explicitly unvalidated. See `examples/reports/benchmarks.json` and the individual logs.

Features still requiring implementation beyond this alpha: global arbitrary-topology decomposition and deformation optimization, full Orca geometry / configuration / slicing integration, exact material coverage and guaranteed removable supports, richer machine-link attachments for imported rotary-stage bodies, controller-specific saved configuration editing, and machine-specific modeled startup / shutdown sequences. Current code uses connected isosurface charts, bounded region-orientation retries, simple support columns and sampled coverage.
