# Architecture and frames

Version 0.4 adds schema-2 `PlateObject`, `MaterialProfile`, `ToolDefinition`, `NozzleProfile`, `MaterialAssignment`, `JobEvent`, recipes and compute contracts. `plate.cpp` owns material/tool planning and persistence helpers; `plate_collision.cpp` restores per-worker prefix scenes, checks docking/whole-plate events and schedules repairs/orders; `plate_controllers.cpp` exports/replays canonical carriage state. The GUI edits and renders these core objects. `compute.cpp` owns the bounded pool and optional plain-buffer C ABI plugins. [Plate model](PLATE_JOBS.md), [event semantics](TOOL_CHANGES.md), [compute boundary](COMPUTE.md).

`fiveaxis_core` has no Widgets dependency. `src/core/types.h` is the project / machine / motion contract. Geometry, FEA, field slicing, motion repair, collision and controller adapters operate on value-type project snapshots. The desktop sends snapshots to QtConcurrent workers and discards results whose input fingerprint changed. The CLI runs the same core.

World and workpiece frames are right handed. CAD length is normalized to mm. E is filament mm, time seconds, joints radians internally, force N, stress MPa. The assembly nozzle axis points from tip into the toolhead. Setup applies a rigid mounting rotation that aligns its zero-pose direction to +Z. `joint.xyz` represents world-space TCP in stored samples. `controller_axes` converts it to the physical carriage origin by compensating the mounted TCP and both head pivots. Simulation, resampling and interval checking interpolate those carriage axes and rotary joints, then reconstruct the TCP. G-code uses carriage XYZ; enable no additional firmware TCP compensation. The optional Klipper extension reconstructs the same TCP using exported pivots and offsets before checking bead flow. Each imported component retains the baked assembly-space meshes, original instance placement and unique nested instance ID.

Rotary bed: `T(pivot) Rx(A) Rz(C) T(-pivot)`. Tilting head: `T(pivotA) Rx(A) T(-pivotA) T(pivotB) Ry(B) T(-pivotB)`. Carriage, first rotary stage and final nozzle links share the compensation translation and receive the appropriate rotation chain. Fixtures attached to the bed and deposited material live in the workpiece frame. Fixed bodies live in world coordinates.

The STEP source hash, meshing tolerance and importer version key the local tessellation cache. Rendering mesh deflection is at least 0.1 mm; collision mesh defaults to 0.02 mm. Collision distance is reduced by tool geometry uncertainty. Independent rendering buffers cache complete triangles and a deposition-prefix index; scrubbing changes the visible prefix and computes the partially deposited active bead. This has no effect on collision validation.

FCL broad-phase managers hold fixed and workpiece-frame obstacles separately. Deposited rounded beads use conservative oriented bounding boxes, shifted below the nozzle-top path. Mesh-mesh distances, intersections and point-in-solid containment are checked. Rigid components on the same link retain their designed overlaps; distinct head links are checked. Explicit assembly interfaces identify component IDs and a bounded box in the first component's CAD frame. Only that region is removed from its interface collision surface; containment outside it remains checked. Intended physical contact clips only the selected nozzle-tip region using an inscribed contact prism with both axial limits and applies locally to active material during extrusion. Non-extruding lift and approach permit positive tip separation below the normal clearance threshold, while still blocking penetration; the remaining nozzle body must maintain clearance. The bed may approach that region but may not be penetrated. Contact-locality and containment-region boundaries are included in interval clearance bounds.

Every trajectory interval is checked from its actual interpolated joints. A conservative Lipschitz displacement bound includes Cartesian motion, rotary travel, pivots, mounted geometry and TCP lever arms. Adaptive subdivision establishes clearance or records an unresolved interval at the depth budget. Extrusion is further split into at most 0.2 mm deposition increments so subsequent portions see previously deposited material. Bead length / E are reconstructed from actual workpiece TCP motion before export.

The scalar-field tetrahedral solve biases build gradients away from tensile principal directions, blends toward a vertical reference to bound gradient norm and tilt, then extracts volumetric isosurfaces. Surface graph distances generate inset walls; stress tangents generate infill streamlines. Curves receive independent region IDs and scheduled support dependencies. The sampled deposition pass checks local lower-layer support proximity, configured bridging distance, gravity angle and E consistency. Its coverage ratio measures tetra-centroid proximity to planned material at the selected infill spacing; it is not a voxel-perfect solid coverage guarantee.

Repair uses alternate IK branches and a bounded deposition cone. Travel repair uses deterministic local OMPL samplers / RRT-Connect seeds, an iteration budget and subsequent interval validation. Retraction is kept once at the repaired endpoint. One final region-orientation retry is permitted, and accepted only after deposition and full geometry checks. This does not yet implement arbitrary decomposition regeneration or a coupled global strength optimizer.

The versioned `.5axis` archive contains JSON geometry, units, mesh uncertainty, FEM, loads, machine configuration, process settings, motion and reports, plus original toolhead STEP. Fixture CAD is embedded in the manifest. Any geometry, machine, controller or trajectory change changes the SHA-256 validation fingerprint. The export gate requires both a matching clear report and completed deposition planning.

Controller semantic replay parses the generated G-code subset, reconstructs positions / E / feed metrics and reruns geometry validation. It does not emulate Duet acceleration blending or unknown machine-specific macros. Klipper qualification additionally runs the pinned native host against a compiled Linux-MCU dictionary. Hardware evidence is recorded separately.
